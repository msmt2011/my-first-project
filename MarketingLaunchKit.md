# Water Tracker Marketing Launch Kit

## Goal
Get the first interested users before paying for App Store launch costs.

## Main Link
Use the public web app link once the updated files are published:
`https://raw.githack.com/msmt2011/my-first-project/main/index.html`

## What the page does
- Lets visitors try the tracker immediately.
- Collects iPhone launch interest.
- Encourages WhatsApp sharing.
- Gives us early signals before spending on Apple Developer and iOS build setup.

## Lead collection
Lead collection is connected to this Google Form:
`https://docs.google.com/forms/d/e/1FAIpQLSfcxnCZBv6OARE0-nBBURwlgx_j-m0tWUOcLxykrrApS2-IrQ/viewform?usp=header`

## Success metrics
- 100 interested users: prepare TestFlight.
- 300 interested users: prepare App Store launch.
- 500+ interested users: consider paid ads and Pro pre-launch offer.

## First paid ads test
Budget: 50-100 SAR.

Audience:
- Saudi Arabia.
- Age 18-40.
- Interests: fitness, health, walking, gym, weight loss, productivity.

Ad copy:
تابع شرب الماء يوميًا بطريقة سهلة.
جرب التطبيق الآن بدون تحميل، وسجل اهتمامك بنسخة iPhone القادمة.

## Weekly review
Every 7 days, check:
- Link visits.
- Waitlist signups.
- How many users say they have iPhone.
- How many users shared the link.
- Feedback messages.

Then decide:
- Improve landing copy.
- Improve app experience.
- Start TestFlight.
- Pause if interest is too low.
